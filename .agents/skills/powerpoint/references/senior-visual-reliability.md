# Senior Visual Reliability

## Connector reliability

Important arrows and relation lines should have metadata: `id`, `sourceId`, `targetId`, `relationship`, `direction`, and optional `anchorPreference`. Validate that the endpoint reaches the intended target or anchor, is not closer to a neighboring target, uses the correct direction, does not cross text unnecessarily, and does not float in empty space. Use stricter, obvious anchors for SENIOR slides.

## Icon categories

- `PEDAGOGICAL_OBJECT`: simplified real object such as a smartphone, computer, photo, folder, document, or keyboard.
- `FUNCTIONAL_ICON`: established symbol such as a lock, camera, phone, magnifier, arrow, STOP, Wi-Fi, or crossed-out eye.
- `ABSTRACT_CUSTOM_ICON`: invented geometry that requires interpretation. Never use it as a primary SENIOR teaching cue.

Assess recognizability as `CLEAR`, `ACCEPTABLE_WITH_LABEL`, `AMBIGUOUS`, or `UNRECOGNIZABLE`. For SENIOR, functional icons normally have labels; labels clarify rather than rescue an incomprehensible drawing. `AMBIGUOUS` and `UNRECOGNIZABLE` require review.

Before inventing an icon, prefer a universal PowerPoint shape, a controlled SVG/vector, or a concrete pedagogical object. A clear text-plus-shape treatment is better than an ambiguous custom icon.
